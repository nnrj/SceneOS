# 运行库与动态依赖策略

SceneOS 同时支持自包含应用和共享运行库。动态依赖是优化手段，不是强制要求。

默认搜索顺序：

1. 应用清单中完整绑定的路径或身份；
2. 应用目录的私有 `lib/`；
3. 应用私有的并列版本存储；
4. 用户级共享库；
5. 系统级共享库。

当前工作目录和任意 PATH 不进入默认库搜索路径。运行时不会联网补依赖，也不会
对宽泛版本范围进行临时求解。

公共库身份包含 ABI 主版本，例如 `scene-ui@1`。不兼容主版本可并列安装，
安装事务必须可回滚。应用可以选择静态链接或携带私有库；系统升级不得覆盖
应用私有依赖。具体 ELF dynamic loader ABI 将在用户态加载器实现前确定。
