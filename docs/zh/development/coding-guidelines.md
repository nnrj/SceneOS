# 编码与接口约定

- 内核 C 标准为 C17，启用严格警告并默认视为错误。
- freestanding 代码不得隐式依赖宿主 libc 或宿主头文件。
- 固定宽度硬件字段使用 `uint*_t`；地址使用能表达完整地址的类型。
- 架构相关汇编仅放在 `arch/<architecture>`。
- 公共接口使用 `scene_` 前缀，头文件使用 include guard。
- 模块通过接口和不透明对象交互，不直接引用其他模块的内部全局变量。
- 所有失败必须形成明确错误或 panic；不得静默继续破坏状态。
- 新增公共契约时同步更新 `docs/zh/api` 和 `docs/en/api`。
- 第三方文件不得直接修改；升级时记录来源提交、许可证和摘要。
- 脚本的清理、覆盖和下载范围必须能从代码中静态确认。
