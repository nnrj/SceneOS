# SceneOS documentation

- [中文文档](zh/README.md)
- [English documentation](en/README.md)

Both language trees use the same top-level classification:

- `project`: product goals, architecture, roadmap, and compatibility policy.
- `development`: information for SceneOS maintainers and contributors.
- `api`: contracts for driver, system-service, and application developers.

The Chinese and English versions are maintained as peers. A design decision is
not complete until both language trees describe the same contract.
